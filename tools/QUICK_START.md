# 🚀 预期差详细页快速生成指南

## 每日操作流程（3分钟搞定）

### 第一步：填写数据

1. 复制 `data/template.json` 为 `data/2026-03-20.json`（日期改为当天）
2. 按模板填写5个预期差的数据

**关键字段说明：**

| 字段 | 说明 | 示例 |
|------|------|------|
| `id` | 唯一标识，英文无空格 | `Hormuz`、`hk`、`storage2` |
| `title` | 预期差标题 | `霍尔木兹海峡封锁规模` |
| `stocks` | 相关标的 | `石油、航运、军工` |
| `size` | 大小 | `large`（大）、`medium`（中）|
| `stars` | 星级 | `⭐⭐⭐⭐⭐` |
| `tag` | 标签文字 | `地缘政治` |
| `tag_class` | 标签样式 | `policy`（红）、`highlight`（黄）|
| `icon` | 标题图标 | `🛢️`、`🇭🇰`、`💾` |

### 第二步：运行生成器

```bash
cd /root/.openclaw/workspace/yixue-dashboard
python3 tools/generate_gap_pages.py
```

### 第三步：复制到 index.html

1. 将生成的详细页HTML复制到 `index.html` 的 `<!-- 预期差详细页 -->` 区域
2. 将生成的清单条目HTML复制到 `<!-- 预期差清单 -->` 区域
3. 删除旧的详细页和清单条目

### 第四步：推送更新

```bash
git add index.html
git commit -m "更新：2026-03-20 预期差清单"
git push origin main
```
