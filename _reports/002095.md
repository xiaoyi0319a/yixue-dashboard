# 生意宝（002095）个股分析报告

## 💡大白话三问

**【这家公司是做什么的？】**
浙江网盛生意宝是孙德良1997年创办（中国化工网起家、2006年上市）的B2B产业互联网老牌公司，两块业务：①B2B电商平台"3+1"——大宗品/工业品/消费品三类电商+供应链金融与期现交易，赚交易差价和服务费（2026前三季营收6.10亿的主要来源，公告口径"主要系供应链业务收入增加"）；②生意社大宗商品数据平台——监测300多个大宗品种的价格行情并发布价格指数，是国内历史最长、品种最全的大宗价格数据资产之一。实控人孙德良数十年未变，近全流通（约2.53亿股）。

**【贵不贵？】**
贵。42.33亿市值对6.10亿营收+前三季扣非137万的组合，PE失效（微利）、PS约6.9倍。主业锚：按平台型电商4-6倍PS只值24-36亿（9.5-14.2元/股），现价16.73元已超上限约18%。也就是说，超过14元的部分全部是"数据资产+题材"的期权定价——市场按"数据要素核心标的"给它估值，但公司至今没有单列过一块"数据业务收入"。

**【有没有故事？】**
有一个真材实料但尚未兑现的故事：数据资产重估。生意社300+品种价格指数体系在数据要素政策（数据资产入表、数据交易场所建设）催化下具备变现想象——价格指数授权、数据产品订阅、产业数据服务，叠加10月底韩国站/全球B2B联盟"日活1500万"的流量故事。另一个被高估的"故事"：营收+48%的高增长——增量几乎全部来自低毛利（7.05%）供应链业务，且供应链金融敞口在扩大（应收票据+149%、短期借款+326.64%），公司已在主动收缩供应链子公司资本金（浙江金宝/联钢减资）。

**【最坏会怎样？】**
最坏=双逻辑同时证伪：2026年报扣非再转亏（前三季137万垫极薄，Q4单季-137万即全年扣非转负）+数据业务全年无收入进展。届时"真实扭亏"与"数据资产变现"两条定价支柱同时塌，估值向主业锚收敛，回看13.9-14.5元主业定价区（距现价约-14%~-17%）。利润质量已经给过提示：前三季归母943万里，杭银消费金融股权公允价值变动收益贡献918万（税前），扣非只剩137万。

2. **现金流是亮点**：经营现金流+4816万，远超净利润，主业回款真实；货币资金5.79亿（Q3末）。
3. **供应链金融敞口扩大**：应收票据+149%（供应链应收票据增加）、短期借款+326.64%（商业承兑汇票已贴现未到期）、信用减值损失-207万（坏账计提减少）——增收的代价是风险资产膨胀；公司反手减资收缩供应链子公司（浙江金宝/联钢），自我纠偏中。
4. **轻杠杆**：负债率25.77%，无重大偿债压力。

- **多头一句话**: "数据要素政策落地在即，生意社300+价格指数是A股稀缺数据资产，期权一旦兑现市值看60亿+。"
- **空头一句话**: "6亿营收、7%毛利、扣非137万，42亿市值买的是零收入的数据故事，大股东刚在17.5-19.6元卖过货。"

### 四、仲裁（小羿视角，非操作建议）

- 价值理由 vs 交易理由清点：多头核心理由4个（数据资产/政策方向/扣非转正/现金流好）中，价值理由3个、交易理由1个；空头核心理由4个（利润质量/估值超锚/减持/零收入）中，价值理由4个、交易理由0个。
- 战场胜负表：①筹码-空 ②业绩估值-空 ③题材-平偏多 ④股东行为-空 ⑤格局-平。
- 仲裁结论：低-中价值（与第一篇Step 4一致）——当前价格更接近空头的定价（期权全价计入），但数据资产真实性给多头保留了20%的翻盘通道；价值理由集中在空头侧，该标的是"交易理由驱动的脉冲标的"，不是价值标的。
- 认输信号清单：**多头认输**=2026年报无数据业务收入披露 或 全年扣非转负；**空头认输**=数据要素政策落地+公司首单数据业务收入公告+年报扣非>500万（衔接第一篇Step 3验证节点：2027-01预告/2027-04年报）。
