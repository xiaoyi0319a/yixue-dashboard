<h2>🔥 大白话三问</h2>

<h3>【这家公司是做什么的？】</h3>
<p><strong>行业归属</strong>：光伏EPC工程 + 半导体材料（转型中）</p>
<p><strong>产业链位置</strong>：</p>
<ul>
<li>原主业：中游——光伏电站EPC工程建设（已亏损，毛利率-6.49%）</li>
<li>新业务（待注入）：上游核心材料——FMM精细金属掩膜版 + EC电致变色膜</li>
</ul>
<p><strong>核心产品/技术</strong>：</p>
<ul>
<li>主业：光伏EPC工程（持续萎缩，2026H1营收仅5045万，同比-15.82%）</li>
<li>新业务1：FMM——OLED显示面板核心材料，国内唯二能量产，打破日本DNP垄断</li>
<li>新业务2：EC膜——全固态电致变色膜，用于智能玻璃/汽车变色天窗，美国SageGlass唯一竞品</li>
</ul>
<p><strong>客户是谁</strong>：</p>
<ul>
<li>EPC业务：政府/央企电站项目（回款极差，应收账款1.82亿，坏账风险高）</li>
<li>FMM未来客户：京东方、维信诺等OLED面板厂</li>
<li>EC膜未来客户：新能源汽车玻璃厂、智能建筑商</li>
</ul>
<p><strong>增长逻辑</strong>：半导体资产注入 → 切入OLED显示+智能玻璃赛道 → 估值从"工程公司"切换为"材料公司"</p>

<h3>【贵不贵？】</h3>
<p>当前股价约<strong>9.22元</strong>，总市值约<strong>61.39亿</strong>，PB约<strong>5.70倍</strong>，PS约<strong>53.20倍</strong>。</p>
<p><strong>传统估值全部失效</strong>（PE 40倍但扣非亏损）。必须用分部期权估值法：</p>
<ul>
<li>光伏残值：5-10亿（净资产10.78亿，资产质量差）</li>
<li>FMM期权：40-60亿（若量产+客户认证）</li>
<li>EC膜期权：10-20亿（远期，商业化尚早）</li>
</ul>
<p><strong>合理市值区间：65-110亿 → 对应股价 9.8-16.5元</strong></p>
<p>当前61亿 → <strong>定价的是FMM部分兑现+EC膜小部分</strong>。贵不贵取决于信哪个故事：信EPC则贵3倍，信半导体则合理偏低。</p>

<h3>【有没有故事？】</h3>
<p><strong>行业景气周期</strong>：光伏EPC是<strong>冬天</strong>（产能过剩，毛利率为负）；OLED显示是<strong>春天</strong>（国产替代加速，FMM卡脖子）；智能玻璃/EC膜是<strong>早春</strong>（技术验证期）</p>
<p><strong>公司真故事</strong>：</p>
<ul>
<li>实控人变更：面板行业老兵彭骞（原精测电子创始人）入主，带来半导体基因</li>
<li>FMM资产：众凌科技产线已建成，国内唯二能量产</li>
<li>已摘帽：2026-08-07撤销ST，消除退市风险</li>
<li>重整计划：法院裁定通过，债权清偿方案已落地</li>
</ul>
<p><strong>公司假故事</strong>："光伏+半导体双主业"——光伏EPC已实质亏损，不会成为增长点；"半年净利润增长124%"——扣非仍亏1770万，利润全靠资产处置和债务重组</p>
<p><strong>预期差</strong>：市场共识是"资产注入=下一个十倍股"，但<strong>注入进度严重滞后</strong>（原计划2026H1完成，至今无实质进展），众凌科技良率、客户认证均未披露。若纠正，有15-30%回调空间。</p>

<h3>【最坏会怎样？】</h3>
<p><strong>证伪信号</strong>：2026年底前无FMM/EC膜注入实质进展；三季报无半导体业务收入；众凌科技FMM良率&lt;70%</p>
<p><strong>验证节点</strong>：</p>
<ul>
<li>2026-10-31（三季报）：是否有半导体业务收入</li>
<li>2026-12-31（年报前）：资产注入是否完成</li>
<li>2027-03-31（年报披露）：FMM是否产生实质收入</li>
</ul>
<p><strong>三情景</strong>：</p>
<ul>
<li>乐观冲15-18元（25%概率）：资产注入完成+FMM量产良率&gt;80%+拿到京东方/维信诺订单</li>
<li>基准横盘8-11元（50%概率）← <strong>最可能</strong>：注入缓慢推进，无实质量产数据</li>
<li>悲观跌回5-6元（25%概率）：注入失败或FMM良率不达标</li>
</ul>
