<h2>🔥 大白话三问</h2>

<h3>【这家公司是做什么的？】</h3>
<p><strong>行业归属</strong>：纺织制造——非织造布（俗称"无纺布"）</p>
<p><strong>产业链位置</strong>：中游——做无纺布卷材的，卖给下游制品厂做成湿巾、卫生巾、纸尿裤、面膜等</p>
<p><strong>核心产品</strong>：</p>
<ul>
<li>水刺非织造布（主力，约70-80%）：湿巾、面膜、卫生用品基材</li>
<li>热风非织造布（约15-20%）：纸尿裤/卫生巾面层材料</li>
<li>长丝超细纤维非织造布（约5%）：高端清洁、工业用材</li>
<li>熔喷非织造布（少量）：医疗防护材料</li>
</ul>
<p><strong>客户是谁</strong>：B2B模式，卖给下游制品厂</p>
<ul>
<li>国内头部：恒安集团（心相印）、维达纸业、金红叶（清风）、杭州豪悦</li>
<li>国际客户：日本LEC等</li>
<li>客户粘性强：进入头部企业供应链需要长周期认证，切换成本高</li>
</ul>
<p><strong>增长逻辑</strong>：产能利用率提升+产品升级（可降解/高附加值）+产业链延伸（汽车防护新材料）→ 营收增长+毛利率修复</p>

<h3>【贵不贵？】</h3>
<p>当前股价约<strong>26.67元</strong>，总市值约<strong>32亿</strong>，PE(TTM)约<strong>31倍</strong>，PB约<strong>1.93倍</strong>，PS约<strong>2.68倍</strong>。</p>
<p><strong>合理股价区间</strong>：</p>
<ul>
<li>如果全年净利7000万（悲观，H1低基数+下半年回落）→ 合理股价<strong>21-25元</strong></li>
<li>如果全年净利8500万（基准，H1已完成3149万+下半年维持）← <strong>最可能</strong> → 合理股价<strong>26-32元</strong></li>
<li>如果全年净利1.1亿（乐观，汽车防护新业务放量+毛利率继续提升）→ 合理股价<strong>33-40元</strong></li>
</ul>
<p>当前26.67元 → <strong>在合理区间的中间位置</strong>。与基准情景对比，<strong>不贵也不便宜</strong>，但已部分定价了业绩拐头和汽车防护新业务预期。</p>

<h3>【有没有故事？】</h3>
<p><strong>行业景气周期</strong>：非织造布行业是<strong>夏天转初秋</strong>（成熟期，增速5-10%，但格局优化+产品升级带来结构性机会）</p>
<p><strong>公司真故事</strong>：</p>
<ul>
<li><strong>业绩拐点确认</strong>：2024年净利仅1233万→2025年8669万（+180%）→2026H1 3149万（+99%），连续高增</li>
<li><strong>毛利率持续改善</strong>：从2024年10.7%→2026H1 13.3%，产能利用率提升+高附加值产品占比增加</li>
<li><strong>汽车防护新材料</strong>：2025年10月收购金圣源51%股权，切入车规级防护车衣，从B2B卷材延伸到B2B2C汽车用品</li>
<li><strong>可降解材料</strong>：年产12000吨湿法可降解水刺非织造布项目投产，顺应环保趋势</li>
</ul>
<p><strong>公司假故事</strong>："储能概念"——10MW/20MWh储能项目已并网，但对利润贡献极小，市场偶发炒作</p>
<p><strong>预期差</strong>：市场共识是"业绩拐点+新业务"，但<strong>汽车防护新业务（金圣源）的收入和利润贡献尚未在财报中体现</strong>。如果Q3/Q4金圣源数据超预期，有20-30%空间；如果不及预期，可能回调15-20%。</p>

<h3>【最坏会怎样？】</h3>
<p><strong>证伪信号</strong>：毛利率重回10%以下；Q3/Q4营收增速掉到10%以内；金圣源并表后亏损</p>
<p><strong>验证节点</strong>：</p>
<ul>
<li>2026-10-31（三季报）：毛利率是否维持13%+；金圣源是否贡献收入</li>
<li>2026年年报：全年净利能否达到8000万以上</li>
</ul>
<p><strong>三情景</strong>：</p>
<ul>
<li>乐观冲35-40元（20%概率）：全年净利1亿+，汽车防护业务放量，估值切换至PE 35-40倍</li>
<li>基准横盘25-30元（55%概率）← <strong>最可能</strong>：业绩符合预期，新业务稳步推进</li>
<li>悲观跌回20-22元（25%概率）：毛利率回落，金圣源不及预期，估值回归PE 25倍</li>
</ul>
