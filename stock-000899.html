🎯 大白话三问

【这家公司是做什么的？】
赣能股份是江西省的"电力平台"——就像省里的"电力国资委"。它不只在发电，更是在帮江西省投资集团（大股东）把能源资产一个个装进上市公司。

核心生意：火电（占99%+）+ 一点水电和新能源。火电装机540万千瓦，占江西省统调火电的16.91%。2025年9月和12月，两台100万千瓦的超超临界火电机组（上高电厂）投产，这是它最大的增量。

增长逻辑：①上高两台百万机组投产 → 年增发电量几十亿度 → 直接贡献营收和利润；②大股东把东电、东津等资产注入 → 解决同业竞争 → 装机和利润双重增厚。
【第一：这价格贵不贵？】
不贵，甚至偏低。

股价14.04元，市值137亿，PE（市盈率）只有13.5倍。电力行业平均PE是32倍，它连一半都不到。

用TTM（滚动四季）利润算，增速约48%，PEG（市盈率÷增速）只有0.28。PEG小于0.5就是显著低估，它只有0.28。

合理股价区间（按18倍PE）：
  • 悲观（全年7亿利润）→ 合理PE 15倍 → 105亿市值 → 10.8元/股
  • 基准（全年8.5亿利润）← 最可能 → 合理PE 18倍 → 153亿市值 → 15.7元/股
  • 乐观（全年10亿利润）→ 合理PE 20倍 → 200亿市值 → 20.5元/股
当前14.04元 → 在合理区间的偏下位置。但有个警示：Q1营收涨了52%，利润只涨了4.7%——成本端（煤价+财务费用）在侵蚀利润。
【第二：有没有故事？】
真故事：装资产进上市公司。
5月11日公告要收购东电公司100%股权，5月26日又签协议收东津发电。这是控股股东江投集团在"往上市公司装资产"——解决同业竞争，同时也是在增厚上市公司利润。如果年内完成并表，直接增厚利润5000万-1亿。

假故事：虚拟电厂+抽水蓄能。
虚拟电厂在申报江西省第一批试点，抽水蓄能120万千瓦在主体施工——这两个概念市场会炒，但短期（1-2年内）不产生利润。是"雾"，不是"底"。

预期差：市场把赣能当成"普通火电周期股"（PE给10-15倍），但它实际上是"省级电力平台+资产注入通道"（应该给18-25倍PE）。这个认知差如果被纠正，有17-31%的空间。
【第三：最坏会怎样？】
证伪信号：如果Q2利润环比下滑（低于1.8亿）+ 煤价反弹超150元/吨 → 故事结束。

三情景：
  • 乐观（25%概率）：夏季高温超预期+煤价低位+收购年内并表 → 全年净利润10亿+ → 股价冲18-20元
  • 基准（55%概率）← 最可能：煤价平稳+上高正常出力+收购年内并表 → 全年净利润8.5-9.5亿 → 股价15-17元横盘
  • 悲观（20%概率）：煤价反弹+来水偏丰挤压火电+收购延迟 → 全年净利润6-7亿 → 股价跌回10-12元
加权预期收益约+15%，风险收益比0.74:1——能赚，但得熬。

验证节点：7月15日Q2业绩预告、8月30日中报、9月30日收购进度。

四句话总结

核心变化：上高机组投产+控股股东装资产，赣能从装机增长迈入内生+外延双轮驱动

估值位置：当前PEG≈0.28，在合理区间的偏下位置，13.5倍PE有安全边际

预期差：市场把平台型电力股当成普通火电周期股，若纠正有17-31%空间

风险点：煤价反弹+来水偏丰挤压火电空间，Q2利润若环比下滑则逻辑受损

演变路径

乐观：如果夏季江西出现极端高温、用电增速超预期+煤价维持低位，则上高机组满发+高电价，全年净利润可冲10-11亿。

基准：如果煤价平稳、利用小时正常、无极端天气，则上高机组正常出力，全年净利润约9-10亿（含东电/东津并表）。

悲观：如果煤价反弹超100元/吨+来水偏丰挤压火电空间，则上高机组出力受限，全年净利润回落至6-7亿。

🏁 Step 4：投资逻辑

⚠️ 中价值——预期差中等，能赚但得熬

当前PE 13.5倍提供了安全边际，PEG 0.28显著低估。但Q1增收不增利暴露了成本端脆弱性，利润弹性受煤价和来水双重制约。真正的超额收益来自"平台溢价"认知差纠正，这需要2-3个月的中报+收购进度验证。

存量博弈——大盘偏弱震荡，电力板块成资金避风港，板块内部轮动。存量博弈下，纯概念仓位要严控，但赣能的底（上高机组）已验证、顶（装资产）有公告支撑，属于"硬逻辑+硬催化"，容错率中等。若大盘反弹，资金可能从电力撤出，需警惕。
