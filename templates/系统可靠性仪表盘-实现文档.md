# 系统可靠性仪表盘 - 实现文档

**版本**: 1.1  
**日期**: 2026-08-07  
**功能**: 在网站首页展示方向整理系统的次日验证效果，帮助用户判断"能不能跟着参与"

**变更记录**:
- 2026-08-07: badge.label 简化，累计天数改由前端 `${o.total_days}` 显示，避免与"近14天"统计口径混淆
- 2026-08-04: 创建模板，整合系统可靠性仪表盘完整实现

---

## 一、术语规范（强制执行）

| 旧用词 | 新用词 | 说明 |
|:-------|:-------|:-----|
| 胜率 | **成功率** | 方向整理推的票次日上涨比例 |
| 收益 | **涨幅** | 次日平均涨跌幅 |
| 连胜 | **连续** | 成功率>50%的持续天数 |
| 连败 | **连续中断** | 成功率<50%的持续天数 |

**禁止在代码、文案、JSON 字段名中使用旧用词。**

## 二、数据流架构

```
下午 15:30 复盘任务                          早上 07:00 网站更新任务
├─ 选股反馈复盘                              ├─ 方向整理（涨停+新闻）
│   ├─ 每日复盘.md                            │   ├─ 生成方向内容
│   ├─ 动态调整.json                          │   ├─ 更新 index.html
│   ├─ 累积统计.json  ← 核心数据源            │   └─ 【新增】同步系统状态
│   └─ 【新增】calc_system_reliability.py     │       └─ sync_system_status.py
│       └─ system-status.json                 │           ├─ 复制 JSON 到 data/
│                                             │           └─ git push
└─ 数据沉淀在 memory/                         └─ 网站实时渲染
```

### 5.2 HTML 插入位置

在 `index.html` 中，**奇门预测 section 之后、涨停方向 section 之前**插入以下代码：

```html
<!-- 系统可靠性仪表盘 -->
<div class="status-section" id="system-status-container">
    <h2>📊 方向整理系统状态</h2>
    <div id="system-status-content">
        <p style="color:#5a6a7a;text-align:center;padding:20px;">加载中...</p>
    </div>
</div>
<script>
(function() {
    const container = document.getElementById('system-status-content');
    if (!container) return;

    // 内联默认数据（当 fetch 失败时显示）
    const defaultData = {
        "badge": { "text": "🔥 连续 3 天", "class": "hot", "label": "历史最长" },
        "overall": { "current_streak_days": 3, "last_14_hot_days": 8, "last_14_cold_days": 6, "last_14_win_rate": 0.5714, "max_win_streak": 3, "max_loss_streak": 2 },
        "directions": {
            "limit_up": { "last_win_rate": 0.75, "last_avg_return": 1.33, "streak_days": 3, "history": [] },
            "news": { "last_win_rate": 1.0, "last_avg_return": 6.13, "streak_days": 3, "history": [] }
        }
    };

    function render(data) {
        const o = data.overall || {};
        const b = data.badge || {};
        const lu = (data.directions && data.directions.limit_up) || {};
        const ns = (data.directions && data.directions.news) || {};

        const winRateClass = (wr) => wr >= 0.7 ? 'hot' : (wr >= 0.5 ? 'neutral' : 'cold');
        const dots = (hist) => {
            if (!hist || !hist.length) return '';
            return hist.map((h) => {
                const cls = (h.win_rate || 0) >= 0.5 ? 'hot' : 'cold';
                return '<div class="streak-dot ' + cls + '" title="' + (h.date || '') + '"></div>';
            }).join('');
        };

        const html = `
    <div class="status-badge-wrap">
        <span class="status-badge ${b.class || 'hot'}">${b.text || '加载中'}</span>
        <span class="status-label">系统处于"${o.current_streak_type === 'win' ? '热' : '冷'}"状态（累计运行${o.total_days || 0}天）</span>
    </div>
    <div class="status-summary">
        近14天：高成功率 ${o.last_14_hot_days || 0} 天 / 低成功率 ${o.last_14_cold_days || 0} 天 (${((o.last_14_win_rate || 0)*100).toFixed(1)}%) · 历史最长连续 ${o.max_win_streak || 0} 天 · 历史最长连续中断 ${o.max_loss_streak || 0} 天
    </div>
    <div class="dir-compare">
        <div class="dir-status-card">
            <h4>🔥 涨停方向 · 昨日验证</h4>
            <div class="win-rate ${winRateClass(lu.last_win_rate || 0)}">${((lu.last_win_rate || 0)*100).toFixed(1)}%</div>
            <div class="meta">平均涨幅 ${(lu.last_avg_return || 0) >= 0 ? '+' : ''}${(lu.last_avg_return || 0).toFixed(2)}% · 连续 ${lu.streak_days || 0} 天</div>
            <div class="streak-bar">${dots(lu.history)}</div>
            <div class="streak-note">绿=高成功率日 红=低成功率日 (左→右 近14天)</div>
        </div>
        <div class="dir-status-card">
            <h4>📰 新闻方向 · 昨日验证</h4>
            <div class="win-rate ${winRateClass(ns.last_win_rate || 0)}">${((ns.last_win_rate || 0)*100).toFixed(1)}%</div>
            <div class="meta">平均涨幅 ${(ns.last_avg_return || 0) >= 0 ? '+' : ''}${(ns.last_avg_return || 0).toFixed(2)}% · 连续 ${ns.streak_days || 0} 天</div>
            <div class="streak-bar">${dots(ns.history)}</div>
            <div class="streak-note">绿=高成功率日 红=低成功率日 (左→右 近14天)</div>
        </div>
    </div>
        `;
        container.innerHTML = html;
    }

    // 优先从 data/system-status.json 加载最新数据
    fetch('data/system-status.json?' + Date.now())
        .then(r => r.ok ? r.json() : Promise.reject('fetch failed'))
        .then(data => render(data))
        .catch(() => render(defaultData));
})();
</script>
```

## 八、badge 状态说明

| badge 样式 | 条件 | 含义 |
|:-----------|:-----|:-----|
| 🔥 连续 N 天 | 连续>=3天，且等于历史最长 | 系统处于最强状态 |
| 连续 N 天 | 连续<3天 | 系统正常热状态 |
| 💀 连续中断 N 天 | 中断>=3天，且等于历史最长 | 系统处于最差状态 |
| 连续中断 N 天 | 中断<3天 | 系统正常冷状态 |

**显示格式**：
- badge 文本（左侧红色标签）：🔥 连续 N 天
- 状态描述（右侧灰色文字）：系统处于"热"状态（累计运行15天）

**注意**：累计天数通过 `${o.total_days}` 从 overall 对象读取，与 badge.label 分离，避免口径混淆。
